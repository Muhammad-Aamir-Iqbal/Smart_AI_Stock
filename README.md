# SmartStock AI

SmartStock AI is a retail intelligence Streamlit application designed for demand forecasting, inventory optimization, and sales opportunity analysis.

## Features
- Weekly and daily demand forecasting
- Profit and stock shortfall calculations
- Product rankings and reorder recommendations
- Multi-location and category filtering
- Smart inventory assistant powered by retrieval and LLM-backed analysis
- CSV, Excel, JSON, and SQLite data ingestion
- WhatsApp-style operational alert workflow

## Tech Stack
- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- FAISS
- Hugging Face transformers
- SQLite

## Run locally

cd "C:\Users\User\Downloads\Compressed\Smart_AI_Stock-main"
